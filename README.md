## 🛠️ O que pratiquei

- Estrutura e semântica do HTML5: títulos, parágrafos, listas, links e formatação
- Imagens, áudio e vídeo, inclusive imagens que mudam de tamanho conforme a tela
- As três formas de aplicar CSS: inline, interno e arquivo externo
- Cores, gradientes, fontes da web e fontes locais
- Seletores por ID, pseudo-classes e o modelo de caixas (`margin`, `border`, `padding`)

## ▶️ Como abrir

Cada exercício e desafio é independente. É só abrir o `index.html` da pasta no navegador:

```bash
git clone https://github.com/mateusrosa0901/html-css.git
```
